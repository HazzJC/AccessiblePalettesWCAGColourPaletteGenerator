## [1.0.0] - 2026-06-07

### Added
- **Palette Generation**: Generate 3 to 16 visually distinct colour swatches distributed evenly across the hue spectrum.
- **WCAG Contrast Validation**: Real-time relative luminance calculation against light (`#F9FAFB`) and dark (`#111827`) backgrounds with numeric contrast ratios.
- **Compliance Badging**: Instant AA and AAA pass/fail indicators for UI design systems and charts.
- **Forced Compliance Mode**: Dynamic lightness adjustment engine to force swatches into AA/AAA thresholds.
- **Custom Hex Validation**: Comparison tool to paste and evaluate existing brand palettes.
- **Live Tool**: Deployed on GitHub Pages at [hazzjc.github.io/AccessiblePalettesWCAGColourPaletteGenerator](https://hazzjc.github.io/AccessiblePalettesWCAGColourPaletteGenerator/).
